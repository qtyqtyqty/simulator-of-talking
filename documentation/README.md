# Simulator of Talking

**Group 331–332 project** — by `qty`, `loonaraxo`, `mon1d`

---

## Геймплей

Два слоя игры:

1. **Мир** (top-down с псевдо-3D перспективой) — ходишь по локации, подходишь к точкам интереса в радиусе (~160px), открывается подсказка действия (заговорить / отдохнуть / зайти в магазин).
2. **Диалог** (карточная мини-игра) — отдельный экран, где и происходит основной геймплей.

### Основной цикл диалога

- В руке 3 карточки-фразы. Каждая — тег (тема) + число (сила, 1–8).
- Карточку тянешь и отпускаешь, как рогатку — она летит в собеседника.
- Формула: `сила карты + модификатор темы у персонажа ≥ случайный порог → успех, иначе провал`. Строго бинарно.
- Порог виден как `?/N`, но перебрасывается заново перед каждым броском — заранее не угадать.
- Успех — отношение растёт (+5…+11%), провал — падает (−5…−11%). Заодно тратится/восстанавливается второй ресурс — «батарейка».

### Углубление механики

*(открывается по прогрессии, не сразу)*

- **Комбо** — можно стянуть в специальную полосу первую карту, потом бросить туда вторую (разной темы) — они сливаются в одну более сильную карточку.
- **Спецтеги** — три особые темы без обычной силы, у каждой своё правило:
  - одна гарантирует провал сейчас, но железный успех следующим ходом;
  - другая удваивает эффект броска;
  - третья не даёт ни плюса, ни минуса, зато перебрасывает силу другой карты в руке.

### Ресурсы

| Ресурс | Поведение |
|---|---|
| **Шкала A** (наверху, всегда на экране) | тратится обратным ходом времени, снижается только победами над персонажами |
| **Шкала B** (батарейка, видна только в диалоге) | тратится на вход в диалог и на неудачные броски, восстанавливается успехами или полным отдыхом. Если падает ниже порога — успехи слабее, провалы больнее (штрафное состояние «истощён») |

### Предметы

Подбираются/покупаются в мире, дают доступ к дополнительным карточкам-фразам в руке; расходуются, когда такую карточку бросили.

### Победное условие

Довести отношение с персонажем до 100% — специальный финальный бросок вместо обычной карты закрывает встречу.
